Konfigurasi Supabase Online DB

Secara default, jika URL Supabase belum dimasukkan, aplikasi menggunakan Local Storage Fallback secara otomatis agar dapat diuji tanpa setup.

Petunjuk Tabel Database SQL:

-- 1. Buat Tabel Messages
CREATE TABLE public.messages (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  sender_name TEXT NOT NULL,
  message TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  is_read BOOLEAN DEFAULT FALSE
);

-- 2. Aktifkan RLS
ALTER TABLE public.messages ENABLE ROW LEVEL SECURITY;

-- 3. Atur Policy Player (Insert Only)
CREATE POLICY "Allow public insert" 
ON public.messages FOR INSERT 
TO anon WITH CHECK (true);

-- 4. Atur Policy Owner (Select/Update/Delete)
CREATE POLICY "Allow anon select and manage" 
ON public.messages FOR ALL 
TO anon USING (true);
